# Code of Ethics — Fox Next Automation Control

**Fox Next** builds **Automation Control** and **Smart Support Bot** to empower creators, businesses, and independent operators with transparent, human-supervised multi-agent automation.

## Core Principles

1. **Human Accountability First**
   - High-impact operations (payments, licensing, external public posts, server infrastructure commands) enforce Human-in-the-Loop (HITL) checkpoints and explicit operator consent.
2. **Privacy & Data Minimization**
   - Ephemeral media uploads used for scheduled social publishing are automatically deleted immediately after dispatch or swept after 24 hours.
   - Users maintain full ownership of their data with one-click encrypted `.fnbackup` portability between Cloud and Local-First Desktop deployments.
3. **Zero Unauthorized Credential Harvesting**
   - Agents never ask users to paste secret keys into plain LLM prompts; secure inline Vault forms isolate secrets from model inference logs.
4. **Synthetic Media Transparency & Audio Integrity**
   - AI-generated voiceovers, imagery, and video teasers follow ethical provenance guidelines and avoid deceptive impersonation without consent.
5. **Anti-Abuse & Fair Resource Use**
   - Public web search and webpage fetching tools respect SSRF network boundaries and rate limits. Use of this toolkit for spam, credential stuffing, or unauthorized infrastructure access is strictly prohibited.
